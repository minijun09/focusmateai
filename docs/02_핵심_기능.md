# 02. 핵심 기능

## 1. 공통 사용 흐름

목표·가용 시간 입력 → 계획 제안 및 학생 확인 → 집중·휴식 → 결과 기록 → 회고·코칭 → 다음 계획 조정으로 이어진다. 처음부터 모든 정보를 요구하지 않고, 첫 세션에 필요한 항목부터 입력받는다.

## 2. 집중 타이머

**목적:** 공부를 시작할 단위를 만들고 집중과 휴식을 구분한다.

- 학생이 집중 길이와 휴식 길이를 선택한다. 초기 제안은 집중 25분, 휴식 5분이며 수정할 수 있다.
- 시작·일시정지·재개·중단을 제공한다. 일시정지 시간은 집중 시간에서 제외한다.
- 세션 종료 시 할 일 완료·일부 완료·미완료와 체감 난이도를 선택적으로 기록한다.
- 중단 사유는 스마트폰 사용·피로·다른 일정·기타 중 선택할 수 있고 건너뛸 수 있다.
- 앱을 떠났다는 이유만으로 스마트폰 사용이나 집중 실패를 추정하지 않는다.
- 집중 실행 중 화면을 떠났다가 돌아오면 선택 가능한 복귀 안내를 제공한다. 타이머를 유지하고 계속하기·쉬기·종료를 선택하게 한다. 특정 앱 감지·차단은 하지 않는다. 상세 조건은 [집중 복귀 안내 설계](06_집중_복귀_안내_설계.md)를 따른다.
- 타이머는 경과 시간을 기록하며 실제 주의 집중 정도를 측정한다고 표현하지 않는다.

**MVP 완료 기준:** 상태 전환 중 시간이 중복 집계되지 않고, 앱 재진입 후 상태를 복원하거나 확인을 요청한다. 비정상 종료로 불확실한 구간은 학생 확인 전 확정 기록에 넣지 않는다.

## 3. 학습 계획

**목적:** 해야 할 일을 오늘 가능한 분량으로 바꾼다.

- 필수 입력은 과목·짧은 할 일·오늘의 가용 시간이다. 선호 집중 길이는 기본값으로 시작할 수 있다.
- 마감일·우선순위·예상 소요 시간은 선택 입력이다.
- 집중, 휴식, 회고를 합친 시간이 가용 시간을 넘지 않도록 제안한다.
- 시간이 부족하면 할 일을 나누거나 일부를 다른 날로 옮길 것을 제안한다. 날짜 이동과 삭제는 학생 확인 후 반영한다.
- 학생은 제안된 항목의 순서·시간·분량을 직접 바꿀 수 있다.
- 확정 이후 항목을 바꾸면 통계 기준이 되는 최종 계획과 실제 실행 기록을 구분해 보관한다.

**MVP 완료 기준:** 계획을 검토·수정·확정할 수 있고, 시간이 초과된 계획은 초과량을 표시하며 줄일 수 있다. 기록이 없는 학생에게도 기본 규칙으로 계획을 제공한다.

## 4. AI 학습 코치

**목적:** 기록을 이해하기 쉬운 다음 행동으로 연결한다.

- 학생이 코칭을 요청하거나 세션·하루 회고를 마쳤을 때 조언을 화면 안에서 제공한다.
- 조언은 근거 요약, 한 가지 실행 제안, 수락·수정·거절 선택으로 구성한다.
- 예: “최근 3회 중 2회에서 어렵다고 표시했어요. 다음 수학 세션을 15분으로 나눠 볼까요?”
- 기록이 적으면 개인 특성을 단정하지 않고 기본 제안을 제공한다.
- 동의 없는 외부 전송, 성격·질환 추정, 성적 보장, 비난 표현을 허용하지 않는다.
- 계획 변경은 수락 후 적용하며, 거절 사유 입력은 선택이다.
- AI 연결 실패나 전송 미동의 시 기본 규칙 기반 안내로 흐름을 이어 간다.

**MVP 완료 기준:** 조언의 근거를 학생이 확인할 수 있고, 거절해도 계획이 유지된다. AI 실패나 잘못된 출력이 타이머·기록 저장을 막지 않는다.

## 5. 보상 시스템

**목적:** 작은 시작과 꾸준한 재시도를 긍정적으로 피드백한다.

- 첫 집중 세션 완료, 중단 후 재시작, 하루 회고 완료 등에 비금전적 배지를 제공한다.
- 같은 조건의 배지는 정해진 단위에서 한 번만 부여한다. 예를 들어 재시작 배지는 하루 1회로 제한한다.
- 길게 공부할수록 무제한으로 보상하는 구조를 피한다.
- 연속 기록이 끊겨도 배지를 회수하거나 벌점을 주지 않는다.
- 타인 순위·확률형 보상·유료 아이템은 제공하지 않는다.
- 배지 표시를 끄더라도 다른 기능을 사용할 수 있다.

**MVP 완료 기준:** 완료된 기록에 근거해 배지가 중복 없이 부여되고, 보상 기능을 꺼도 계획·통계에 영향이 없다. 전체 기록 삭제 시 획득 이력도 삭제한다.

## 6. 통계

**목적:** 학생이 자신의 학습 흐름을 돌아보고 다음 계획을 조정하게 한다.

| 지표 | 정의 | 표시 원칙 |
| --- | --- | --- |
| 일별·주별 집중 시간 | 확정된 세션의 실제 실행 시간 합계 | 휴식·일시정지 제외, 중단 전 실행 구간 포함 |
| 과목별 시간 | 과목에 연결된 집중 시간 합계 | 과목 미지정 기록은 별도 표시 |
| 계획 항목 완료율 | 완료로 표시한 항목 수 ÷ 최종 확정 계획 항목 수 | 일부 완료는 분자에서 제외, 계획 변경 사실 표시 |
| 중단·재시작 | 중단 횟수와 같은 날 중단 후 새로 시작한 세션 여부 | 중단을 실패 점수로 바꾸지 않음 |
| 체감 난이도 | 학생이 선택한 쉬움·보통·어려움 기록 | 미응답을 보통으로 간주하지 않음 |

- 계획 항목이 없는 날의 완료율은 0% 대신 ‘계획 없음’으로 표시한다.
- 하루 구분은 학생이 설정한 시간대를 기준으로 하며, 자정을 넘는 실행 시간은 날짜별로 나눈다.
- 기록이 없는 기간은 ‘기록 없음’으로 표시하고 학습 능력이나 성적을 추정하지 않는다.
- 자신이 이전에 남긴 기록과 비교하며 다른 학생과의 순위는 제공하지 않는다.

**MVP 완료 기준:** 통계가 원본 기록과 일치하고, 기록 수정·삭제가 관련 통계에 반영된다. 일별·주별 보기와 과목별 요약을 제공한다.

## 7. 알림과 데이터의 공통 규칙

- 외부 알림은 기본 꺼짐이며, 학습 리마인더는 별도 동의 후 하루 최대 1회만 보낸다. 반응이 없어도 재촉하지 않는다.
- 조용한 시간의 초기 제안은 22:00~08:00이다. 학생이 바꿀 수 있으며, 해당 시간에 예정된 리마인더는 건너뛰고 나중에 몰아서 보내지 않는다.
- 타이머 종료는 앱 안에서 먼저 표시한다. 외부 종료 알림은 별도 선택 사항이며 활성 세션의 종료 시 1회만 제공하고, 조용한 시간에는 보내지 않는다.
- 잠금 화면 알림에는 과목·할 일·완료율 등 학습 내용을 넣지 않는다.
- 학습 기록은 기본 90일 보관 후 관련 통계와 함께 삭제하는 안을 적용한다. 학생이 더 일찍 삭제할 수 있게 한다.
- 외부 AI에는 선택 동의 후 필요한 요약만 전송한다. 알림·AI 전송·개인화 설정을 각각 제어할 수 있게 한다.
