# 01. 프로젝트 기획

## 1. 프로젝트 개요

FocusMate AI는 고등학생이 학습 목표를 작은 행동으로 나누고, 집중 세션과 회고를 반복하며 자신에게 맞는 공부 습관을 만드는 학습 집중 관리 AI 에이전트다.

현재 문서는 개발 전 기획안이다. 아래 문제와 효과는 사용자 인터뷰 및 시범 운영으로 검증할 가설이며, 검증된 성과로 표현하지 않는다.

## 2. 문제 정의

| 상황 | 학생이 겪는 어려움 | 해결 방향 |
| --- | --- | --- |
| 공부를 시작하려는 순간 | 숏폼·SNS·게임으로 주의가 이동하고 시작을 미룸 | 지금 실행할 작은 할 일과 짧은 집중 세션 제시 |
| 계획을 세울 때 | 해야 할 일과 가용 시간을 연결하기 어려움 | 과목별 할 일을 시간 단위로 나누고 우선순위 정리 |
| 공부 도중 | 방해나 피로로 중단한 뒤 다시 시작하기 어려움 | 중단을 실패로 취급하지 않고 재시작·휴식 선택 제공 |
| 하루를 마칠 때 | 무엇이 잘됐고 무엇을 바꿔야 할지 알기 어려움 | 기록과 짧은 자기 평가를 바탕으로 다음 계획 제안 |

스마트폰 사용 자체를 비난하거나 모든 집중 문제의 원인으로 단정하지 않는다. 계획 부담, 피로, 과목 난이도 등도 학생이 선택적으로 표현할 수 있게 한다.

## 3. 타깃 사용자

### 우선 사용자

- 스마트폰 사용으로 공부 시작이나 지속에 어려움을 느끼는 고등학생
- 혼자 공부할 때 계획 수립과 시간 배분을 도와줄 도구가 필요한 학생
- 긴 기록 작성이나 복잡한 설정 없이 학습 습관을 점검하고 싶은 학생

### 대표 사용 시나리오

학생이 오늘 공부할 과목과 60분의 가용 시간을 입력한다. 서비스는 수학 25분, 휴식 5분, 영어 25분, 회고 5분을 제안한다. 학생이 확인한 뒤 타이머를 시작하고, 종료 후 완료 여부와 체감 난이도를 선택한다. 다음 계획에서는 이 기록을 참고하되 학생이 직접 수정할 수 있다.

### 초기 범위에서 제외하는 사용자 역할

보호자·교사·학교 관리자의 학생 기록 조회 기능은 제공하지 않는다. 향후 공유 기능을 검토하더라도 학생의 선택과 공유 범위를 별도로 설계해야 한다.

## 4. 해결 목표와 검증 방법

| 해결 목표 | 확인할 지표 | 검증 방법 |
| --- | --- | --- |
| 공부 시작 부담 줄이기 | 계획 확정부터 첫 세션 시작까지 걸린 시간 | 동의한 시범 사용자 기록과 인터뷰 |
| 실행 가능한 계획 만들기 | 계획 항목 완료율, 계획 수정 사유 | 완료 항목 수 ÷ 확정 계획 항목 수와 회고 분석 |
| 중단 후 회복 지원 | 중단 후 같은 날 재시작한 비율 | 중단 경험이 있는 날 중 재시작한 날의 비율 확인 |
| 학생이 조언을 유용하게 느끼게 하기 | 조언 수락·수정·거절, 선택적 유용성 평가 | 제안 결과와 짧은 설문 확인 |
| 기록과 알림의 부담 낮추기 | 기록 불편 의견, 알림 끄기·불편 신고 | 인터뷰와 설정 변경 사유 확인 |

초기 목표 수치는 기초 조사 이후 정한다. 학습 시간 증가만을 성공으로 보지 않고, 학생이 느끼는 부담과 휴식의 적절성을 함께 확인한다. 성적 향상이나 집중 문제의 치료를 보장하지 않는다.

## 5. 제품 범위

### 초기 MVP에 포함

- 학생의 목표·가용 시간·선호 집중 길이 입력
- 일일 학습 계획과 집중·휴식 타이머
- 세션 종료 기록 및 선택형 회고
- 기록에 근거한 짧은 AI 코칭과 승인 기반 계획 조정
- 간단한 성취 배지와 개인 일별·주별 통계

### 초기 MVP에서 제외

- 다른 앱의 사용 내역 자동 수집, 화면·키 입력 감시, 앱 강제 차단
- 학교 계정 연동, 성적표 수집, 성적 예측과 입시 판단
- 문제 풀이 자동화, 무제한 대화형 학습 상담
- 보호자 감시, 친구 간 순위 경쟁, 금전성 보상

## 6. 개인정보 및 사용 경험 원칙

1. **최소 수집:** 이름·학교·연락처·정확한 위치·연락처 목록을 요구하지 않는다. 학습 목표는 과목과 짧은 할 일 중심으로 받는다.
2. **기록 보호:** 초기에는 계정 없는 기기 내 저장을 우선 검토한다. 학생은 전체 기록 열람·삭제 및 기록 기반 개인화 해제를 할 수 있어야 한다.
3. **보관 제한:** 상세 학습 기록은 기본 90일 후 삭제하는 안을 검증한다. 상세 기록에서 파생된 개인 통계도 같은 기간과 삭제 범위에 맞춘다.
4. **AI 전송 선택:** 외부 AI를 사용하는 경우 전송 대상과 목적을 먼저 설명하고 선택 동의를 받는다. 동의하지 않아도 기본 계획·타이머·통계를 사용할 수 있다.
5. **알림 제한:** 외부 알림은 기본 꺼짐이다. 선택한 일일 학습 리마인더는 하루 최대 1회로 제한하며, 조용한 시간과 즉시 끄기를 제공한다.
6. **통제보다 지원:** 결석·중단·낮은 완료율을 비난하지 않는다. 긴 공부를 유도하는 알림이나 보상을 만들지 않는다.

90일 보관과 알림 기본값은 제품 기획안이다. 실제 출시 전 대상 연령, 운영 지역, 외부 AI 제공자의 데이터 처리 조건에 맞춰 동의·삭제 절차를 확인한다.

## 7. 개발 전 확인할 질문

- 학생이 가장 어려워하는 순간은 시작, 지속, 계획 중 무엇인가?
- 하루 기록에 어느 정도의 입력 부담을 허용하는가?
- 집중 세션 길이와 휴식 방식은 어떻게 달라지는가?
- AI 요약 전송에 동의할 수 있는 정보 범위는 어디까지인가?
- 타이머의 백그라운드 동작이 필요한 기기와 사용 환경은 무엇인가?
