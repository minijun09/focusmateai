# FocusMate AI
고등학생이 작은 학습 목표를 세우고, 집중·휴식·회고를 반복하며 자신만의 공부 습관을 만드는 웹 앱

## 사용할 수 있는 기능

| 기능 | 현재 동작 |
| --- | --- |
| 집중·휴식 타이머 | 시간을 설정하고 시작·일시정지·재개·종료할 수 있습니다. 일시정지와 휴식 시간은 집중 기록에서 제외합니다. |
| 세션 회고 | 목표를 완료·일부 완료·미완료로 저장하고, 체감 난이도를 선택적으로 남깁니다. |
| 맞춤 공부 계획 | 과목·할 일·예상 시간·우선순위를 입력합니다. 가용 시간 안에 휴식과 회고 2분을 포함한 초안을 만들고 수정·확정합니다. |
| 성취 배지 | 첫 목표 완료, 세션 3회 완료, 서로 다른 3일 기록, 중단한 날 재시작을 기록합니다. 같은 세션 ID는 중복 계산하지 않습니다. |
| 집중 패턴 분석 | 최근 7일의 실행 시간·과목별 합계·평균 세션 길이·세션 목표 완료율을 확인합니다. 시간대 제안은 해당 시간대 기록이 3회 이상일 때 제공합니다. |
| 학습 코치 | 고민을 선택하거나 질문을 입력하면 근거와 짧은 제안을 제공합니다. 제안은 수락하거나 넘길 수 있습니다. |
| 집중 복귀 안내 | 집중 실행 중 화면이 5초 이상 숨겨졌다가 돌아오면 안내할 수 있습니다. 직전 안내 후 60초 안에는 반복 표시하지 않습니다. |

모바일에서는 공부 설정 다음에 타이머가 나오고, 넓은 화면에서는 설정이 타이머 왼쪽에 있습니다. 계획 항목을 선택하거나 코치 제안을 수락하면 다음 타이머를 준비하며, 시작은 학생이 직접 합니다. 세션 실행·일시정지·복원 확인·회고 중에는 타이머 설정과 계획 확정을 제한합니다.

계획의 집중·휴식·회고 항목은 자동으로 이어서 실행되지 않습니다. 각 세션과 휴식은 타이머 버튼으로 시작합니다. 할 일은 목록에 유지되고, 확정 계획의 집중 항목 완료 표시는 저장한 세션 결과에 따라 갱신됩니다.

## 추천과 분석 기준

외부 AI가 연결되지 않으면 기기 내 규칙으로 추천합니다. 기록이 3회 미만이면 선택한 집중 시간을 유지합니다. 최근 최대 5회 중 ‘어려움’이 2회 이상이거나 중단이 2회 이상이면 제안 시간을 최대 15분으로 줄일 수 있습니다. 기본 코칭은 시작 부담·피로·계획·기록 회고에 대한 미리 정한 전략을 사용하며, 자유로운 대화형 모델은 아닙니다.

최근 7일의 목표 완료율은 **완료 세션 수 ÷ 기록된 세션 수**입니다. 일부 완료와 미완료도 분모에 포함합니다. 확정 계획의 완료 항목 수와는 다른 지표입니다. 일별 시간은 브라우저의 현지 시간대와 세션 종료 날짜를 기준으로 합산하며, 자정을 넘긴 세션을 날짜별로 나누지는 않습니다.

타이머는 실행 시간을 기록하며 실제 주의 집중이나 성적을 측정하지 않습니다. 화면이 숨겨졌다는 사실만으로 유튜브·인스타그램 등 특정 앱을 식별하거나 차단하지 않습니다. 복귀 안내는 타이머를 자동으로 멈추거나 세션을 실패로 처리하지 않으며, 휴식·일시정지·종료 상태에서는 표시하지 않습니다.

## 시작하기

프로젝트 설정과 동일한 Node.js 24, pnpm 11.25.0을 사용합니다.

```sh
pnpm install
pnpm dev
```

Vite가 표시하는 로컬 주소를 엽니다. 기본 주소는 `http://127.0.0.1:5173/`입니다.

```sh
pnpm test       # 타이머·학습 규칙·AI 요청 및 응답 검증
pnpm build      # 타입 검사와 프로덕션 빌드
pnpm preview    # 빌드 결과를 로컬에서 확인
```

AI 테스트는 모의 응답을 사용합니다. 테스트 통과가 실제 모델 연결 성공을 의미하지는 않습니다.

## 선택적 외부 AI

API 키가 없어도 기기 내 규칙 기반 추천을 사용할 수 있습니다. 계획 제안·코칭·패턴 해석을 위한 서버 연결 코드가 구현되어 있으며, 실제 모델을 사용하려면 키 설정과 앱 내 전송 동의가 필요합니다.

1. `.env.example`을 `.env.local`로 복사합니다.
2. `OPENAI_API_KEY`와 필요하면 `OPENAI_MODEL`을 설정합니다. 모델 미지정 시 코드의 기본값은 `gpt-4.1-mini`입니다.
3. 로컬 서버를 재시작하고 코치 영역에서 외부 AI를 켭니다. 동의는 이번 방문에만 유지합니다.

질문 원문 또는 선택한 고민, 선호 집중 길이, 가용 시간, 과목·예상 분량·우선순위, 최근 7일 집계만 전송합니다. 할 일 제목과 개별 학습 기록은 제외합니다. 키는 서버에 보관하며, 비밀 키에 `VITE_` 접두어를 붙이지 않습니다.

서버는 구조화된 조언을 요청하고 반환된 문구와 집중 길이를 검증합니다. 분당 최대 5회, 동시 요청 1개, 응답 대기 20초로 제한합니다. 연결 실패나 잘못된 출력은 기본 안내로 대체합니다. 동의를 철회하면 진행 중인 요청을 취소하고 해당 응답을 적용하지 않습니다.

AI 엔드포인트는 로컬 Vite 개발·미리보기 서버에서 동작합니다. 정적 빌드는 기본 기능을 제공하며, 외부 AI에는 별도 서버가 필요합니다. 실제 학생에게 외부 AI를 제공하기 전에는 제공자의 데이터 처리 조건과 적절한 동의 절차를 확인해야 합니다.

## 데이터와 복원

계획·할 일·세션 기록·코칭 내역·설정은 현재 브라우저에 저장합니다. 다른 기기·브라우저·사이트 주소와 자동 동기화하지 않으며, 브라우저 데이터를 지우면 함께 삭제됩니다.

- 앱을 불러올 때 최근 90일 범위를 벗어난 세션 기록을 제외하고 남은 기록을 다시 저장합니다. 백그라운드에서 주기적으로 삭제하는 서비스는 아닙니다.
- 배지는 보관된 기록에서 다시 계산하며 별도의 영구 획득 이력으로 저장하지 않습니다. 배지 표시는 끌 수 있습니다.
- 코칭 내역은 최대 10개 대화를 보관합니다. 미확정 계획 초안은 저장하지 않고, 확정 계획은 현지 날짜가 오늘인 경우에만 복원합니다.
- 새로고침 후 실행 중인 타이머가 발견되면 마지막 저장 이후 시간을 포함할지 선택합니다. 복원 후에는 일시정지 상태에서 직접 재개합니다.
- 전체 기록 삭제는 학습 기록·타이머 상태·저장된 학습 도구 데이터·진행 중인 AI 작업을 초기화합니다. 저장 실패는 화면에 안내합니다.

휴식하거나 하루 쉬었다는 이유로 벌점을 주지 않습니다.

## 소스 구성

- `src/main.tsx`: 타이머·세션 회고·복원·앱 배치.
- `src/timer.ts`: 경과 시간·일시정지·복귀 안내 규칙.
- `src/StudyHub.tsx`: 계획·배지·분석·코칭 화면과 저장 상태.
- `src/study.ts`: 계획 생성·추천·통계·배지 계산 규칙.
- `server/ai.mjs`: 로컬 AI 미들웨어와 입력·출력 검증.
- `src/*.test.ts`, `server/*.test.mjs`: 자동 검증.
- `docs/`: 한국어 제품 기획과 설계 문서. 향후 목표를 포함하며, 현재 구현 동작은 위 설명을 기준으로 합니다.
