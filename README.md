# focusmateai

FocusMate AI는 고등학생이 스마트폰의 숏폼, SNS, 게임 등으로 흐트러진 학습 흐름을 회복하도록 돕는 개인 맞춤형 학습 집중 관리 AI 에이전트다.

현재는 **프로젝트 기본 기획 단계**다. 이 저장소에는 문제 정의, 핵심 기능, AI 에이전트 구조, MVP 개발 계획을 정리하며, 아직 코드는 작성하지 않는다. 기존 프로젝트 제목과 `.gitattributes`는 보존한다.

## 프로젝트 목표

- 학생이 가용 시간에 맞는 학습 계획을 쉽게 세우게 한다.
- 집중 타이머와 휴식으로 공부를 시작하고 다시 이어 가게 한다.
- 학습 기록을 바탕으로 AI가 실행 가능한 다음 행동을 제안하게 한다.
- 성적이나 공부 시간 경쟁보다 계획 실행과 꾸준한 재시도를 지원한다.

## 주요 사용자

스마트폰 사용으로 공부 시작이나 지속에 어려움을 느끼고, 스스로 학습 습관을 만들고 싶은 고등학생을 우선 대상으로 한다. 보호자와 교사는 초기 MVP의 기록 열람 사용자가 아니다.

## 핵심 기능

| 기능 | 제공 가치 |
| --- | --- |
| 집중 타이머 | 집중·휴식 시간을 구분하고 중단 후 재시작 지원 |
| 학습 계획 | 과목·할 일·가용 시간에 맞는 실천 가능한 계획 제안 |
| AI 학습 코치 | 기록과 자기 평가를 활용한 짧은 조언 및 계획 조정 제안 |
| 보상 시스템 | 시작·완료·재시도에 대한 비금전적 성취 피드백 |
| 통계 | 개인의 계획 실행, 집중 시간, 변화 추세 확인 |

## 기본 원칙

- **개인정보 최소 수집:** 이름, 학교, 전화번호 없이 시작할 수 있도록 기획한다. 초기 MVP는 계정 없이 기기 내 저장을 우선 검토한다.
- **학습 기록 보호:** 목적에 필요한 기록만 보관하고, 열람·삭제를 학생이 직접 제어한다. 외부 AI 전송은 사전 선택 동의를 받고 최소한의 요약으로 제한한다.
- **과도한 알림 방지:** 외부 알림은 기본 꺼짐으로 두고, 사용자가 설정한 시간과 빈도 안에서만 제공한다.
- **학생의 결정권:** AI의 계획 변경은 제안으로 제공하고 학생의 승인 후 반영한다. 거절·중단에 불이익을 주지 않는다.

## 초기 MVP 범위

목표 입력 → 일일 계획 확인 → 집중 세션 → 짧은 회고 → 다음 계획 조정의 한 흐름을 우선 구현할 계획이다. 기본 보상과 일별·주별 통계를 포함한다.

스마트폰 앱 자동 감시·강제 차단, 성적 예측, 문제 풀이 자동화, 보호자 감시 화면, 친구 순위표, 유료 보상은 초기 범위에서 제외한다. 우선 플랫폼은 반응형 웹이며 기술 스택은 **React + TypeScript + Vite**로 확정한다. 앱 소스는 `focusmate-web/`에 구성할 계획이다. AI 제공자와 출시 일정은 요구 검증 후 결정한다.
